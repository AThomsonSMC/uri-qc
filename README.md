This is a collection of code written by Adam Thomson for The Quantum Computing program at URI.

## PHY571
### Math Methods for Quantum Computing

A collection of basic python scripts and jupyter notebooks to establish foundational concepts.

## PHY572
### Quantum Foundations

Exploring how to apply operators on qubit states and build basic quantum circuits using qiskit

## PHY573
### Introduction to Quantum Computing

Implementations of early quantum algorithms:
- Week2: Quantum Teleportation
- Week3: Deutsh-Jozsa Algorithm
- Week4: Bernstein-Vazirani Algorithm & Simon's Algorithm
- Week5: Quantum Fourier Transform
- Week6: Shor's Algorithm
- Week7: Grover's Algorithm

## PHY574
### Advanced Quantum Computing

Demonstrating the necessity of Quantum Error Correction and Phase Estimation
- Week1: QEC through repetition
- Week2: QEC repition continued & Measurement Error Mitigation
- Week3: Using Quantum Phase Estimation to measure the value of Pi
- Week4: Performing a Quantum Walk on a hypercube

## Genomic Grover
### Capstone Project

A proof of concept for using Grover's Quantum Search algorithm on a genomic dataset.
